## Descripción

Programa que almacena información de columnas de un dataset (Encuesta Permanente
de Hogares) y roles de acceso (docente, investigador, analista), y genera un
informe filtrado y ordenado según el rol solicitado.

## Estructura del proyecto

```
.
├── src/
│   ├── datos.py      # COLUMNAS y ROLES (la configuración)
│   └── informe.py    # generar_informe() y mostrar_informe() (la lógica)
├── notebook_actividad1.ipynb   # ejecución de ejemplo
├── Bitácora.md
└── README.md
```

## Cómo ejecutar

Abrir `notebook_actividad1.ipynb` en Jupyter y correr las celdas en orden.
